# Contributing

Welcome to Agent Web Commons. Keep patches narrowly scoped and reference the
[Altdown draft](https://altdown.org/1.0/) section affected.

- Open an issue for protocol ambiguities; do not silently reinterpret the standard.
- For a hard-to-reverse decision, propose an ADR in its own docs-only PR.
- An ADR requires explicit human acceptance before implementation.
- Link the active feature plan, task IDs, and verification results in each PR.
- Add deterministic offline tests (including rejected cases) for changed behavior.
- Update current-state `docs/ARCHITECTURE.md` when a boundary changes.
- Contributions to this tools repository are under Apache-2.0.
- The separately published Altdown specification is licensed CC BY-SA 4.0.
